# LLM手動運用ガイド（APIなし）

## 目的

このドキュメントは、`Codex` や `Claude Code` を **アプリへのLLM API組み込みなし** で運用するための最小ルールをまとめたものです。

## 結論

- 手動運用なら API 実装なしで進められる
- ユーザー向け機能として自動実行したい場合は、別途 API 連携が必要

## APIなしでできること

- 実装作業の補助（コード生成、修正、リファクタ）
- テスト実行や不具合調査の補助
- PRレビュー補助（観点抽出、差分チェック、回帰確認）
- ドキュメント作成・更新

## APIなしではできないこと

- エンドユーザー操作をトリガーにした自動実行
- 本番環境での常時バックグラウンド処理
- 外部サービスへ自動送信するプロダクト機能

## 標準フロー（手動）

1. 変更要求を Issue / メモに明文化する
2. `Codex` / `Claude Code` に実装または調査を依頼する
3. ローカルでテストを実行する（例: `npm run lint`, `npm run test:excel`）
4. 差分を人が確認してコミットする
5. PRで CI を通してから `main` に反映する

## 安全ルール

- LLMの提案は必ず人が最終確認する
- 秘密情報（APIキー、トークン）をコードへハードコードしない
- 破壊的操作（DB更新、本番反映）は承認済み手順でのみ実行する
- `main` 直pushではなく、必ず PR 経由で反映する

## API連携を検討するタイミング

次のどれかに当てはまる場合は、API連携やMCPサーバー実装を検討します。

- 同じ作業を頻繁に自動実行したい
- ユーザー操作に応じてリアルタイム実行したい
- 複数システムを連携した業務処理を組み込みたい
